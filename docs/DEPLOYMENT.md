# 部署与资源

本仓库保持服务器代码目录结构；原始服务器路径仍可能出现在脚本和配置中。不要直接复制环境目录。

1. 克隆仓库，阅读根目录 `README_流程使用说明.md`，准备Linux及对应Python/R环境。
2. 检查代码中的 `/media/` 绝对路径，按部署位置配置软件、流程和资源路径；尤其入口shell、YAML配置、Rscript路径及报告模板引用。
3. 按 [资源目录清单](server_resource_inventory.json) 准备资源。此清单只是当前部署的目录记录，数据库文件未上传；不能仅凭清单复原完整数据库。
4. 准备独立项目目录、输入矩阵/FASTQ和样本表，明确分组、批次、配对关系及比较方向。
5. 先执行输入验证或小规模测试，再启动完整分析。结果写入独立目录，不提交到代码仓库。

转录组还需物种匹配的FASTA、GTF、HISAT2/SOAP索引、注释映射和富集资源；config/species中的模板记录原部署版本。depends_script内的物种KEGG .ko数据需另行准备。



上传不等于在新服务器完成部署验证。本次验证边界见VALIDATION.md。

原服务器模板中“不要改路径”等描述仅适用于原部署；在自己的服务器上克隆后，必须改为实际安装路径。
